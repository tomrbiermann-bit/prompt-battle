# Fremde Bestandteile

- `public/vendor/qrcode.js`: QR Code Generator for JavaScript von Kazuhiko Arase, MIT-Lizenz (Lizenzhinweis steht in der Datei).
- `public/fonts/patrick-hand-*.woff2`: Schrift "Patrick Hand" von Patrick Wagesreiter, SIL Open Font License 1.1 (siehe `public/fonts/LICENSE-patrick-hand.txt`).

- `assets/fonts/PatrickHand-Regular.ttf`: dieselbe Schrift für den PDF-Bericht, aus den beiden Teilschriften zusammengeführt (siehe `assets/fonts/LICENSE-patrick-hand.txt`).
- `assets/fonts/LiberationSans-Regular.ttf`, `LiberationSans-Bold.ttf`: Schrift "Liberation Sans", SIL Open Font License 1.1, unveränderte Originaldateien (siehe `assets/fonts/LICENSE-liberation.txt`).
- `pdfkit` (MIT-Lizenz) mit seinen Abhängigkeiten: wird beim Installieren über npm geladen und erzeugt den PDF-Bericht.

Alle Figuren und Grafiken in `public/img` wurden eigens für dieses Projekt gezeichnet.
